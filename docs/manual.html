概览OVERVIEW

wg-web 是一个给 WireGuard 网关做账号与访问权限管控的 Web 平台。 它把「给谁、放行到哪台内网机器的哪个端口」这件原本要手改配置文件的事， 做成了一张张可点击的卡片：账号是卡片、目的地是卡片、目的地包还是卡片 —— 点开卡片就是授权，勾两下就生效，网关侧的 nftables / AllowedIPs 自动同步。

整个前端零框架、零构建：一个 app.js + 一份 styles.css， 放到任意静态目录就能跑，也方便按需改造。

特性FEATURES

🗂 卡片式管理

VPN 用户、IP-端口池、目的地包全部以卡片呈现：头像、状态、授权数量一眼可见，点整卡即进入编辑，右下角保留删除。

🖱 可视化授权

打开用户抽屉，勾选目的地或整个目的地包即可授权；切换「白名单 / 黑名单」模式时，勾选含义自动反转并给出醒目提示。

🌐 黑名单 + 全代理

每用户可叠加开启：黑名单（默认放行、勾选即禁止，鎏金徽标）与全代理（全部流量经网关转发、外网走 NAT，淡紫徽标）；双开时卡片光晕在两色间缓慢共振。

🛡 就地校验

提交时对必填、IP 格式、端口格式（单端口 / 区间 / 多段，与服务端同规则）逐项校验：失败项红光晕 + 下方原因 + 轻微晃动；编辑过程不打扰，点外部未保存才弹提示拦截。

✋ 长按批量管理

移动端长按任意卡片即进入批量管理并勾选该条，配合蓄力光环动画；未再改动勾选时，点空白处可直接退出。

🎛 协议多选

IP-端口条目的 TCP / UDP 可同时勾选，网关按协议逐条生成放行规则，一次授权两种协议一起生效。

📱 竖屏自适应

侧栏自动收为底部导航（滑动高亮），表格与卡片按屏宽切换形态，长按、点选、滑动都有对应动效。

📜 访问追踪

每条新连接的放行/拒绝都有记录；管理员操作独立审计，满足「谁在什么时候改了什么」的可追溯要求。

🔐 密钥不落盘

用户私钥加密存储、仅在生成客户端配置时解密下发；生成文件强制纯 ASCII，中文姓名不会再导致导入失败。

🎨 深 / 浅双主题

设置页一键切换，滑动高亮、渐变、发光等动效在两套主题下都有对应配色。

授权流程HOW IT WORKS

  • ① 建目的地 —— 在「IP-端口池」新增一张卡片：名称 + IP + 端口 + 协议（TCP/UDP 可同时勾选）。
  • ② 组目的地包 —— 把多条目的地组合成一个「目的地包」，例如「研发常用」「运维必备」。
  • ③ 建 VPN 用户 —— 新增用户即生成密钥对并分配 VPN 地址；此时不需要下载配置。
  • ④ 点卡片授权 —— 打开用户抽屉，勾选目的地/目的地包，保存；黑名单模式下勾选的变成「禁止项」；也可叠加开启全代理（全部流量经网关转发）。
  • ⑤ 下载配置 —— 授权变化后会提示重新下载 .conf；文件名与内容均为纯 ASCII，可直接导入客户端。配置首行内嵌 wg-meta 元数据（姓名 / 模式 / 网段），标准客户端完全兼容。黑名单 / 全代理模式下会自动注入隧道内 DNS（服务端 WG_CLIENT_DNS，务必配置公共解析），否则全量进隧道的流量会因本机 DNS 被网关默认拒绝而"握手成功却打不开网页"。
  • ⑥ 网关自动生效 —— 网关代理按最新授权生成 nftables 规则（按协议逐条放行），客户端 AllowedIPs 同步更新。
小提示：长按任意卡片可快速进入批量管理；编辑弹窗在有未保存修改时，点击周围不会意外关闭——改过的输入框会标黄并提示，再次点外部即放弃修改。若配置含中文姓名，请使用下方配套客户端导入。

配套客户端WG COMPANION

平台配套的独立客户端 wg-companion （Windows / macOS / Android），把「重新下载配置 → 导入 → 开关隧道」收敛成一件事：

  • 导入即识别 —— 解析配置内嵌的 wg-meta：界面显示真实姓名、授权模式徽章（白名单 · 黑名单 · 全代理）与被授权网段。
  • 一键开关隧道 —— 无需打开 WireGuard 官方程序：Windows 走官方 wireguard.exe 服务化接口（随系统自启）、macOS 走 wg-quick、Android 内嵌官方 GoBackend。
  • 自动更新配置 —— 权限变更后重新下载同名配置覆盖，客户端自动感知并在隧道在线时自动重下发。
  • 同源设计语言 —— 淡紫 × 鎏金、卡片与徽章、启动 / 点击 / 连接全套动画。

快速部署DEPLOY

git clone https://github.com/496793028/wg-web.git
cd wg-web/server
npm install
cp .env.example .env          # 填好 DB_*/WG_* 后
node server.js                # 默认 http://0.0.0.0:8787

首次访问会进入初始化页创建管理员；SEED_DEMO=1 可注入演示数据体验完整流程。

网关侧配合 gateway/vpn-sync.py（systemd 服务 vpn-sync）， 从 /api/gateway/grants 拉取授权并生成 nftables 规则。

安全设计SECURITY

  • 口令存储：scrypt 加盐哈希；首次登录强制改密。
  • 会话：HttpOnly Cookie + 服务端会话表，可按账号强制下线。
  • 权限模型：按模块的「无权限 / 仅查看 / 可修改」三级授权，接口层逐一校验。
  • 高危操作：黑名单切换、批量删除等需手动输入「确认」二次放行。
  • 密钥：AES 加密落盘，主密钥来自环境变量，可独立轮换。
  • 审计：全部管理动作入库（时间 / 操作人 / 类型 / 对象 / 来源 IP）。
