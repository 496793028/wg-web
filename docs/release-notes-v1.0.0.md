# wg-web v1.0.0

首个正式发布：以「**卡片 + 可视化授权**」为核心的 WireGuard 权限管控平台。

## 亮点
- **卡片式管理**：VPN 用户 / IP-端口池 / 目的地包全部卡片化，点整卡即编辑，右下角保留删除。
- **可视化授权**：打开用户抽屉勾选目的地或目的地包即完成授权；白名单 / 黑名单一键切换（含义自动反转并提示）。
- **协议多选**：IP-端口条目可同时勾选 TCP 与 UDP，网关按协议逐条生成放行规则。
- **移动端**：长按卡片进入批量管理（蓄力光环动效）；竖屏卡片化自适应，侧栏收为底部导航。
- **动效**：导航 / 底栏 / 标签页滑动游标、标签切换入场、全站卡片点击涟漪、长按蓄力光环。
- **安全**：scrypt 口令哈希、密钥 AES 加密落盘、三级模块权限、高危操作二次确认、操作审计。
- **配置生成**：纯 ASCII 输出（文件名与内容），中文姓名不再导致客户端导入失败。
